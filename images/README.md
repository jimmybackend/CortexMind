# CortexMind Images

Esta carpeta contiene la documentación visual de CortexMind.

Aquí se almacenarán diagramas, mapas funcionales, representaciones tipo resonancia, vistas 3D del cerebro artificial y otros recursos gráficos del proyecto.

## Convención sugerida

- `cortexmind-brain-mri.png` — mapa funcional tipo resonancia.
- `cortexmind-architecture.png` — arquitectura general del sistema cognitivo.
- `cortexmind-brainpilot.png` — visualización de BrainPilot 3D.

Las imágenes representan conceptos funcionales de CortexMind y no deben interpretarse como modelos médicos o neuroanatómicos exactos.
